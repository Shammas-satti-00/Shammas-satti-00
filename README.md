## About

I'm a **Computer Science graduate (2025)** from **PMAS Arid Agriculture University, Rawalpindi**. I develop interactive 3D experiences and real-time systems with a focus on gameplay programming, responsive controls, simulation mechanics, and practical optimization.

My professional game-development experience includes a space-combat project and a flight simulator. Outside Unity, I have built projects in AI/ML, computer vision, web development, and C++; I'm also learning Solidity and EVM/Web3 fundamentals.

I like working across the full gameplay loop: understanding a mechanic, designing its logic, implementing it in code, and refining it through testing and debugging.
